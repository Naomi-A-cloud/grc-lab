# GlobalHealth Connect Information Security Charter

## 1. Purpose

The purpose of this Information Security Charter is to establish a clear governance framework for protecting GlobalHealth Connect's information, systems and services.

The Charter defines security authority, responsibilities, reporting requirements and key security principles.

## 2. Scope

This Charter applies to:

- All GHC employees.
- Contractors and relevant third parties.
- Information systems and cloud services.
- Patient and business information.
- Applications and databases.
- Devices and network infrastructure.
- Acquired organisations and their relevant systems and information.

## 3. Authority

The Board provides overall oversight of information security.

The CEO is responsible for ensuring that information security supports GHC's business objectives.

The Security Steering Committee provides cross-functional security governance and reviews significant security risks.

The CTO is responsible for technical security leadership.

The Compliance Officer provides compliance oversight and monitors applicable regulatory requirements.

All employees are responsible for following approved information security policies and reporting security concerns.

## 4. Roles and Responsibilities

### Board of Directors

- Provide information security oversight.
- Review significant security risks.
- Receive regular security reports.
- Provide oversight of major security incidents.

### Chief Executive Officer

- Provide executive leadership for information security.
- Ensure security supports business objectives.
- Approve major security priorities.
- Escalate significant risks to the Board.

### Chief Technology Officer

- Lead technical security activities.
- Oversee security controls for cloud systems.
- Review technical security risks.
- Support security incident management.

### Chief Financial Officer

- Review the financial impact of security risks.
- Support appropriate security investment.
- Consider security requirements when allocating resources.

### Security Steering Committee

- Review security risks and metrics.
- Monitor remediation activities.
- Review major security issues.
- Recommend security priorities.
- Escalate significant risks to executive management.

### IT Manager

- Implement approved security controls.
- Manage operational security activities.
- Track vulnerabilities and remediation.
- Support incident response.

### Compliance Officer

- Monitor applicable regulatory requirements.
- Conduct or support compliance assessments.
- Identify compliance gaps.
- Track compliance remediation.

### Employees and Contractors

- Follow approved security policies.
- Protect GHC information.
- Complete required security awareness training.
- Report suspected security incidents.

## 5. Security Principles

GHC will use the following principles to guide information security decisions:

### Risk-Based Approach

Security decisions should consider the likelihood and impact of risks.

### Least Privilege

Users should receive only the access required to perform their duties.

### Accountability

Security responsibilities should have clearly assigned owners.

### Defence in Depth

Multiple security measures should be used to reduce the impact of individual control failures.

### Continuous Improvement

Security controls and governance processes should be reviewed and improved regularly.

### Compliance

GHC will consider applicable legal, regulatory and contractual requirements when managing information security.

## 6. Reporting

Information security reporting should provide management and the Board with clear information about:

- Significant security risks.
- High-risk incidents.
- Vulnerability and patching status.
- Security awareness performance.
- Compliance gaps.
- Outstanding remediation actions.
- Security control performance.

Significant or unresolved risks should be escalated through the Security Steering Committee to executive management and, where appropriate, the Board.

## 7. Review and Approval

This Charter should be reviewed at least annually or when there are significant changes to GHC's business, technology, regulatory requirements or organisational structure.

The CEO is responsible for executive approval of the Charter, with Board oversight.

Changes to the Charter should be documented and communicated to relevant stakeholders.

## 8. Expected Outcome

The Charter establishes a consistent approach to information security governance across GlobalHealth Connect.

It provides clear authority, accountability and reporting arrangements while supporting the organisation's business and security objectives.
