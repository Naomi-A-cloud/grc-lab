# GlobalHealth Connect — Security Steering Committee Meeting Agenda

## Meeting Purpose

To review the proposed password policy and agree on a risk-based approach that provides appropriate security without creating unnecessary operational friction.

## Meeting Topic

Password Policy Review

### Current Proposal

- 16-character minimum password length
- Complex password requirements
- Password changes every 30 days
- No password manager currently included

### Alternative Proposal

The CTO recommends:

- Multi-factor authentication (MFA)
- Secure password management
- Strong password requirements
- Reduced reliance on frequent password changes

---

## Agenda

### 1. Opening and Meeting Objectives

- Confirm meeting purpose.
- Confirm attendees.
- Review the decision required.

### 2. Current Password Policy Proposal

The IT Manager will explain the proposed 16-character password policy and the security risks it is intended to address.

### 3. Technology Perspective

The CTO will explain the operational concerns associated with frequent password changes and present the MFA and password-management alternative.

### 4. Risk Assessment

The committee will assess:

- Credential compromise risk
- Account takeover risk
- User experience
- Operational impact
- Implementation cost
- Compliance requirements
- Technical feasibility

### 5. Options Analysis

The committee will compare:

Option A — Traditional Password Controls

- 16-character passwords
- Complex passwords
- Password changes every 30 days

Option B — Modern Authentication Controls

- Strong passwords
- MFA
- Secure password manager
- Monitoring and access controls

### 6. Decision

The committee will:

- Select the preferred approach.
- Identify any additional controls required.
- Assign action owners.
- Establish implementation deadlines.

### 7. Escalation

If the committee cannot reach an acceptable risk-based decision, the issue will be escalated to the CEO.

### 8. Action Review

The committee will record:

| Action | Owner | Due Date | Status |
|---|---|---|---|
| Finalise password policy | IT Manager / CTO | TBD | Open |
| Assess MFA implementation | CTO | TBD | Open |
| Review compliance requirements | Compliance Officer | TBD | Open |
| Evaluate password manager options | IT Manager | TBD | Open |

---

## Expected Outcome

The meeting should produce a documented, risk-based password policy decision that balances security, usability, operational requirements and compliance.
