# CEO Briefing — Password Policy Decision

To: Sarah Chen, CEO  
From:  Security Steering Committee  
Subject:  Password Policy Decision  
Date:  2026

## Purpose

The Security Steering Committee reviewed the proposed password policy for GlobalHealth Connect.

The discussion focused on balancing strong security controls with usability and operational requirements.

## Issue

The IT Manager proposed:

- 16-character passwords
- Complex password requirements
- Password changes every 30 days
- No password manager

The CTO raised concerns that frequent password changes could create unnecessary user friction and recommended using MFA and secure password management.

## Governance Assessment

The committee considered:

- Credential compromise risk
- Account takeover risk
- User experience
- Operational impact
- Implementation requirements
- Compliance needs
- Technical feasibility

The committee's approach is to select controls based on the level of risk rather than relying on password complexity alone.

## Recommendation

The Security Steering Committee recommends a modern authentication approach that includes:

1. Strong password requirements.
2. Multi-factor authentication (MFA).
3. Secure password management.
4. Appropriate access controls.
5. Monitoring for suspicious authentication activity.
6. Periodic review of authentication risks.

This approach provides multiple layers of protection while reducing unnecessary password-reset friction.

## CEO Decision Required

The CEO is asked to support the recommended risk-based approach and authorise the relevant teams to develop and implement the updated password policy.

## Expected Business Outcome

The recommended approach should strengthen protection against credential compromise while supporting employee productivity and reducing unnecessary operational friction.

The policy should be reviewed periodically to ensure that security controls remain appropriate as the organisation's technology, workforce and threat environment change.
