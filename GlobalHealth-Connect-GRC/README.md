# GlobalHealth Connect - Information Security Governance

## Project Overview

This project presents an information security governance assessment for GlobalHealth Connect (GHC), a fictional health-tech organisation.

The project applies practical GRC concepts to assess governance weaknesses, define accountability, improve security reporting, and develop a governance maturity roadmap.

## Project Areas

1. Governance Blueprint
2. Information Security Charter
3. Board Security Reporting
4. Security Steering Committee
5. Governance Maturity Assessment

## Organisation

GlobalHealth Connect is a fictional mid-sized health-tech organisation that operates a cloud-based patient management platform.

## Disclaimer

GlobalHealth Connect is a fictional organisation created for an academic and portfolio-based GRC exercise.
