# GlobalHealth Connect RACI Matrix

## Purpose

This RACI matrix defines responsibility and accountability for key information security governance activities at GlobalHealth Connect.

## RACI Definitions

- **R - Responsible:** Performs the work.
- **A - Accountable:** Owns the final decision or outcome.
- **C - Consulted:** Provides advice or input.
- **I - Informed:** Receives updates or information.

## Governance RACI Matrix

| Governance Activity | Board | CEO | CFO | CTO | IT Manager | Compliance Officer | Senior Developer | HR Manager |
|---|---|---|---|---|---|---|---|---|
| Information security policy approval | A | A | C | C | C | R | I | I |
| Security risk review | I | A | C | R | R | R | C | I |
| Incident response planning | I | A | I | R | R | C | C | C |
| Security metrics and reporting | I | A | C | R | R | C | I | I |
| Compliance assessment | I | A | C | C | C | R | I | C |
| Security awareness and training | I | A | I | C | C | R | I | R |
| Vulnerability management | I | I | I | A | R | C | R | I |
| Major security incident escalation | A | A | C | R | R | C | C | I |

## Accountability Model

The matrix establishes clear ownership for important governance activities.

The CEO provides executive accountability, while the CTO and IT Manager lead technical and operational security activities. The Compliance Officer is responsible for compliance assessments and provides input into security governance decisions.

The Board provides oversight of major security risks and significant incidents.

## Expected Outcome

The RACI matrix reduces uncertainty about who performs, owns, advises on and receives information about security governance activities. It also supports clearer escalation and accountability across GlobalHealth Connect.
