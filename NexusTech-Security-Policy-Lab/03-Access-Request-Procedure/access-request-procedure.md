# User Access Request Procedure

## Purpose

This procedure establishes a controlled process for granting user access to NexusTech information systems.

## Process

### 1. Access Request

The user's manager submits an access request specifying:

- User name
- Department
- Role
- Required system
- Required access level
- Business justification

### 2. Manager Approval

The user's manager reviews the request and confirms that the access is required for the user's responsibilities.

### 3. Security or System Owner Review

The relevant system owner or authorised security representative reviews the requested access.

### 4. Provisioning

IT provisions the approved access according to the organisation's access control standards.

### 5. Verification

The request is documented and the provisioned access is verified.

### 6. Access Review

User access should be periodically reviewed to identify unnecessary or excessive permissions.

### 7. Access Removal

Access must be removed when employment ends, a user changes role or the business requirement no longer exists.

## Evidence

Examples of evidence may include:

- Approved access request
- Manager approval
- System owner approval
- Access provisioning record
- Access review record
- Termination or access removal record
