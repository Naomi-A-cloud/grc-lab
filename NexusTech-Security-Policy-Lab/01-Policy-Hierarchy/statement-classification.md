# Security Statement Classification

| Statement | Classification | Reason |
|---|---|---|
| Employees must protect company information. | Policy | Establishes organisational direction. |
| Privileged accounts must use MFA. | Standard | Defines a mandatory technical requirement. |
| Access requests must be approved by the user's manager before provisioning. | Procedure | Defines an operational process. |
| Users should avoid accessing sensitive systems from public Wi-Fi. | Guideline | Provides recommended security behaviour. |

## Governance Principle

Correct classification prevents confusion between management requirements, technical controls, operational processes and recommended practices.
