# NexusTech Security Policy Hierarchy

## Purpose

The purpose of this hierarchy is to establish clear governance over information security documentation.

## 1. Policy

Policies define management direction, objectives and mandatory organisational expectations.

**Example:**

NexusTech employees must protect company information and use organisational systems responsibly.

## 2. Standard

Standards define specific mandatory requirements that support a policy.

**Example:**

Multi-factor authentication must be enabled for privileged accounts.

## 3. Procedure

Procedures explain the steps required to perform a specific security activity.

**Example:**

The IT team must follow the documented access request and approval process before creating a user account.

## 4. Guideline

Guidelines provide recommended practices that help users meet security objectives.

**Example:**

Users should avoid connecting to sensitive systems through unsecured public networks.
