# Policy Hierarchy

This evidence bundle demonstrates how NexusTech Solutions structures its information security documentation.

The hierarchy establishes the relationship between policies, standards, procedures and guidelines.

## Documents

- `policy-hierarchy.md` - Defines the governance hierarchy.
- `statement-classification.md` - Classifies example security statements.

## Governance Principle

NexusTech uses the following hierarchy:

**Policy ? Standard ? Procedure ? Guideline**

This structure helps distinguish mandatory organisational direction from detailed operational instructions and recommended practices.
