# NexusTech Security Policy Lab

## Project Overview

This project demonstrates the development and governance of information security policies and procedures for a fictional organisation, NexusTech Solutions.

NexusTech Solutions is a growing cloud-based ERP company with 250 employees. The organisation handles sensitive client information and has expanded into financial and healthcare sectors.

The organisation identified weaknesses in its existing security documentation, including unclear policy requirements, inconsistent procedures and limited accountability.

This project develops a structured security policy framework to improve governance, security awareness, accountability and compliance readiness.

## Objectives

The project aims to:

- Establish a clear security policy hierarchy.
- Separate policies, standards, procedures and guidelines.
- Develop an enforceable Acceptable Use Policy.
- Create a User Access Request Procedure.
- Develop a security communication and training plan.
- Define a policy review and maintenance process.
- Improve security governance and accountability.

## Governance Framework

NexusTech uses the following documentation hierarchy:

**Policy ? Standard ? Procedure ? Guideline**

Policies provide high-level direction.

Standards define mandatory security requirements.

Procedures explain how security requirements are performed.

Guidelines provide recommended security practices.
