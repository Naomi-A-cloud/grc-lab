# Security Communication and Training Plan

## Objective

The objective is to ensure employees understand their security responsibilities and know how to respond to common security risks.

## Communication Activities

| Activity | Audience | Frequency | Owner |
|---|---|---|---|
| Security awareness training | All employees | Annual | Security/GRC |
| Security updates | All employees | As required | Security/GRC |
| Phishing awareness | All employees | Periodic | Security |
| Policy acknowledgement | Relevant users | On policy update | HR/GRC |
| New employee security briefing | New employees | During onboarding | HR/IT |

## Key Topics

Training should cover:

- Password and authentication security
- Phishing and social engineering
- Data protection
- Acceptable use
- Incident reporting
- Remote working security
- Access control responsibilities

## Evidence

Training attendance, policy acknowledgements and communication records should be retained as evidence of awareness activities.
