# Evidence Management

## Purpose

This directory contains technical evidence collected during the Linux security control assurance assessment.

## Evidence Categories

### Auditd

Evidence related to Linux audit logging and security events.

### Logs

Authentication and system log evidence.

### Lynis

Linux security assessment results.

### Access Control

User, group, privilege, and access control evidence.

### SIEM

Security monitoring and detection evidence.

## Evidence Principles

Evidence should be:

- Relevant
- Accurate
- Traceable
- Time-stamped where possible
- Related to a specific control
- Protected from unauthorized modification

## Evidence Naming

Evidence files should use clear names that identify the activity.

Example:

auditd-login-events.txt

failed-login-analysis.txt

lynis-security-assessment.txt

user-access-review.txt
