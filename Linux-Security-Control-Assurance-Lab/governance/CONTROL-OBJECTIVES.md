# Security Control Objectives

## 1. Access Control

### Objective

Ensure only authorized users can access the Linux system.

### Evidence

- User accounts
- Group memberships
- Sudo configuration
- Authentication logs

---

## 2. Authentication Monitoring

### Objective

Detect and review successful and failed authentication attempts.

### Evidence

- Authentication logs
- Failed login events
- Successful login events
- SSH activity

---

## 3. Audit Logging

### Objective

Maintain security audit records for important system activities.

### Evidence

- Auditd configuration
- Audit rules
- Audit logs
- Audit search results

---

## 4. System Monitoring

### Objective

Monitor important system events and identify suspicious activity.

### Evidence

- System logs
- Authentication events
- Privilege changes
- File access events

---

## 5. Security Configuration

### Objective

Identify insecure Linux configurations and recommend improvements.

### Evidence

- Lynis results
- Configuration reviews
- Security recommendations
- Hardening findings

---

## 6. Incident Detection

### Objective

Identify security events that may require investigation or escalation.

### Evidence

- Log analysis
- Alert examples
- Event investigation
- SIEM monitoring documentation
