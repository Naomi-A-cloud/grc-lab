# Security Control Testing

## Control Testing Method

Each control will be reviewed using the following process:

1. Identify the control
2. Define the control objective
3. Identify expected evidence
4. Collect evidence
5. Test the evidence
6. Determine the control status
7. Document findings
8. Recommend remediation
9. Track remediation

## Control Status

The following statuses will be used:

- Effective
- Partially Effective
- Ineffective
- Not Tested
