# Project Scope

## Project Name

Linux Security Control Assurance Lab

## Purpose

The purpose of this project is to demonstrate how Linux security controls can be monitored, tested, documented, and reviewed from both a technical security and GRC perspective.

## Scope

The project covers:

- Linux authentication monitoring
- User and privilege monitoring
- System event monitoring
- Audit logging
- Log analysis
- Security configuration review
- Vulnerability and hardening assessment
- Security control testing
- Evidence collection
- Gap identification
- Remediation tracking
- GRC reporting

## Out of Scope

The project does not include:

- Production systems
- Real customer data
- Destructive security testing
- Penetration testing
- Malware deployment
- Attacks against third-party systems

## Environment

The project is designed as a controlled security lab environment.

All testing activities should be performed only on systems owned or authorized for testing.

## Expected Outcome

The final outcome will demonstrate the ability to connect technical Linux security evidence with security controls, risks, findings, and remediation activities.
