 Linux Security Control Assurance Lab

## Project Overview

This project demonstrates a practical Linux security and GRC control assurance assessment.

The lab connects technical Linux security activities with governance, risk, compliance, evidence management, control testing, and remediation tracking.

The project is designed to demonstrate how a GRC, security, or cloud security analyst can:

- Collect technical security evidence
- Review access and privileged permissions
- Analyze authentication and security events
- Test security controls
- Identify control gaps
- Assess security risks
- Map technical findings to ISO/IEC 27001 controls
- Document remediation activities
- Track control status
- Define control closure requirements
- Report control assurance results
